# Seller Command Center release scope

- Role-aware Seller Command Center at `/admin/today` for active sales roles.
- Admin/team roll-up available at `/admin/seller-command-center`.
- Canonical Sales Catalog powers public `/pricing`, homepage package cards, and seller package reference.
- Public Pricing Admin controls public visibility and canonical inclusion scope without a duplicate data store.
- Existing Sales Catalog remains the price/product-settings editor.
- Existing Payment Process Controls remains the payment-schedule editor.
- Existing quotation snapshots remain historical records.
- Deterministic focus queue prioritizes overdue follow-ups, payment verification, quotation follow-up after the configured delay, and open opportunities missing a future next step.
